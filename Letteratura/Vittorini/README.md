# Elio Vittorini · Il mondo offeso e la forma

PWA didattica standalone, progettata mobile-first per Safari su iPad.

## Avvio locale

Servire la cartella con un server HTTP, per esempio:

\`\`\`bash
python3 -m http.server 8080
\`\`\`

Aprire \`http://localhost:8080/Letteratura/Vittorini/\`.

## Contenuti

Sei sezioni didattiche, ciascuna con lezione, sintesi, saperi irrinunciabili,
vocabolario, mappa SVG, test con feedback e recupero, appunti e persistenza
locale. Non sono richieste dipendenze esterne.
