SVEVO - LIBRO VIVO (PWA)

Contenuto:
- index.html: applicazione principale
- styles.css: design responsive dark/light
- app.js: lezioni, mappe, quiz, taccuino, navigazione
- manifest.webmanifest + service-worker.js: installabilità PWA e cache progressiva
- assets/pdf: materiali originali in PDF
- assets/icons: icone PWA
- assets/thumbs: anteprime dei PDF

Come provarla in locale:
1. Decomprimere lo zip.
2. Aprire la cartella in un piccolo server locale.
   Esempio da terminale: python3 -m http.server 8080
3. Aprire nel browser: http://localhost:8080

Nota:
Aprendo index.html direttamente dal file system la navigazione funziona, ma alcune funzioni PWA
(service worker/installazione) richiedono http://localhost o HTTPS. Su GitHub Pages funziona come PWA.
